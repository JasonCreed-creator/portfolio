# 이진철 — MICE를 다시 설계하다 · Portfolio (HTML)

MICE 전략가 포트폴리오 발표자료(PPTX 26장)의 **HTML 버전**입니다.
원본 슬라이드의 레이아웃·타이포·컬러를 좌표 단위로 재현한 웹 슬라이드 덱으로,
브라우저에서 바로 열람할 수 있습니다.

## 열어보기

- `index.html`을 브라우저에서 열면 됩니다. 별도 빌드·서버가 필요 없습니다.
- GitHub Pages를 켜면 (Settings → Pages → Deploy from a branch) 웹에서 바로 공유할 수 있습니다.

## 조작법

| 입력 | 동작 |
|---|---|
| `→` `Space` `PgDn` / `←` `PgUp` | 다음 / 이전 슬라이드 |
| `Home` / `End` | 처음 / 마지막 슬라이드 |
| `M` 또는 좌하단 ☰ | 목차(26장) 열기 |
| `F` 또는 우하단 ⛶ | 전체화면 |
| 좌우 스와이프 | 모바일 슬라이드 이동 |
| `#/12` 해시 | 특정 슬라이드 딥링크 |

인쇄(`Ctrl/Cmd+P`) 시 슬라이드별 1페이지로 출력됩니다.

## 구성

```
index.html   # 뷰어 + 26장 슬라이드 전체 (단일 파일)
assets/      # 슬라이드 이미지·아이콘 (PPTX 미디어 추출본)
```

- 슬라이드는 2880×1620 고정 스테이지에 절대좌표로 배치되고, 화면 크기에 맞춰 자동 스케일됩니다.
- 폰트는 [Pretendard](https://github.com/orioncactus/pretendard) (jsDelivr CDN)를 사용합니다. 오프라인에서는 시스템 폰트로 대체됩니다.
- 브라우저와 PowerPoint의 글리프 폭 차이는 한 줄 텍스트에 한해 미세 가로압축으로 자동 보정됩니다.
